Tiny Wins - third-party notices
================================
Tiny Wins is a self-contained web app (HTML, CSS, JavaScript). It contains NO third-party code, libraries, frameworks, web fonts or icon sets, and it loads nothing from the network except (a) when you tap an external link and (b) the optional lofi player, which streams music over HTTPS from Wikimedia Commons only after you press play.

Not third-party
---------------
App icon (icon.svg, favicon.svg, icons/*, icon-*.png, favicon.ico, apple-touch-icon.png, the Windows .ico, the macOS .icns and the Android launcher icons): original artwork created for Tiny Wins (three soft cushion steps with a smiling star on top, in slate blue, sage green, soft sand and butter yellow), drawn from plain geometric shapes and gradients. It uses no third-party artwork, fonts or icon sets, and is covered by the same licence as the app.
Fonts: none bundled; the system font stack is used. The check mark in the UI is a Unicode character drawn by the device font.
Emoji: none are used by the app; any emoji a user types are drawn by the device's own emoji font.
All synthesized sounds (brown noise, soft noise, calm tones) are generated in the browser with the Web Audio API.
